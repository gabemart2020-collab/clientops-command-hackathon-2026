# @clientops/web

Next.js 15 / React 19 web presentation layer and deterministic demo harness.

## Phase 2 vertical slice

Provides a runnable demonstration interface for the ClientOps vertical slice:

- Client selection (Acme Labs, Northstar Health, Meridian Retail, Atlas Studio).
- Executive review preparation action trigger.
- High-visibility Delivery Health Badge (**AT RISK** for Acme Labs).
- Factual talking points and evidence-backed risk findings.
- Interactive Evidence Drawer displaying underlying raw database records.
- Open commitments and recent activity feeds.
- Protocol Execution Trace verifying calls traveled through the official `@modelcontextprotocol/client` over Streamable HTTP.
- Clean error banner if the MCP server is unreachable.

## Running

```sh
pnpm dev:web
# Visit http://localhost:3000/demo
```
